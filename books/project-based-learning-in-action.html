Project-Based Learning in Action

A Practical Guide to Designing, Teaching, Assessing, and Sustaining Meaningful Learning

Project-based learning can produce deep, memorable learning—or weeks of busy activity. The difference is design.Project-Based Learning in Action is a practical field guide for K-12 teachers, instructional coaches, and school leaders who want projects that protect rigor while expanding student agency. Using the BUILD cycle, Zahir Hasan shows how to begin with worthy learning, frame authentic problems, guide inquiry, teach collaboration, use critique and revision, assess individual understanding, and recover when projects drift.

Inside this book you will find:

Twenty-three chapters on designing, teaching, assessing, and sustaining high-quality PBL

Six complete project models across grade bands and subjects

Twenty adaptable project starters

Planning templates, rubrics, family communication samples, and a day-by-day first project

An honest reading of the research, equity from the first week, and AI treated as a useful assistant—not a substitute

This is not a collection of project ideas. It is a working system for making knowledge usable.
