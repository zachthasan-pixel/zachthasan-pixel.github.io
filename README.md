# Dr. Zahir Hasan — Author Website

Official author site for the children's fantasy series *The Whispering Realms* and *The Elk Kingdom Chronicles*.

**Live site:** https://zahirhasan.com  
**GitHub Pages:** https://zachthasan-pixel.github.io

### Custom Domain
- Apex domain `zahirhasan.com` points to this repository via A records.
- `www.zahirhasan.com` is set to permanently redirect (301) to `https://zahirhasan.com`.
- CNAME file is configured for the apex domain.
